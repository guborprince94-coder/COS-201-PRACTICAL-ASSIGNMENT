## Programs

| File | What it does |
|------|--------------|
| `SimpleCalculator.java` | Reads two numbers and prints their sum, difference, product, quotient and remainder. |
| `AverageCalculator.java` | Reads three scores and prints their total and average. |
| `ItemCost.java` | Reads an item name, unit price and quantity, then prints the subtotal, 7.5% VAT and total cost. |

## Requirements

- Java Development Kit (JDK) 8 or later
- Check your install with: `javac -version`

## How to compile

Open a terminal in the folder containing the files and run:

```
javac SimpleCalculator.java AverageCalculator.java ItemCost.java
```

## How to run

```
java SimpleCalculator
java AverageCalculator
java ItemCost
```
